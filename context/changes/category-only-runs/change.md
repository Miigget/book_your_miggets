## Notes

Organizer can create a run with a map category and no specific map; that category shows on the run card. Roadmap S-14 / FR-022 / US-07. Map is already optional; store category on the run using catalog difficulty values rather than inferring it from a missing map. Failure mode to avoid: a card with neither map nor category.
