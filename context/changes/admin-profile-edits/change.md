## Notes

S-16: Admin can edit a player's nickname and KoG points from the existing admin player page (/admin/users/{id}), mark points as verified after an in-game check, and accept or deny nickname-change requests from verified members. PRD: FR-023, FR-024, US-10. Extends S-09 admin player page; does not add a second profile. Out of scope: player labels (S-17).
